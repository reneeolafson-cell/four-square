# The founder's vision

Four Square is the product; Alberta Aligned is the company concept. This document preserves the reasoning from the supplied “Plan curriculum delivery” conversation. It is a working direction, not a set of irreversible decisions.

## The problem behind the planner

The original idea was physical curriculum cards: outcomes that could be spread out, grouped into weekly and monthly stacks, rearranged, and stored together. Planning is a visual thinking process. Teachers need to see relationships, progression, gaps, and possibilities before committing to a schedule.

Existing planning often leaves the relationships in the teacher's working memory: which outcome a lesson supports, how much teaching time remains, which worksheet pages belong to Monday, where the slides are, and what evidence of learning to watch for. Searching, copying, organizing, printing, and remembering consume preparation time.

Four Square should hold those connections so the teacher does not have to. Accessibility, including reduced cognitive load for teachers with ADHD, belongs in the original design. Colour alone must not carry meaning, keyboard alternatives should accompany dragging, and busy planning and focused teaching need different interfaces.

## Four connected elements

- **Curriculum:** what needs to be learned?
- **Time:** when can it be taught?
- **Resources:** what will I use?
- **Assessment:** how will I know?

The working principle is **enter information once; use it everywhere**. A planning card connected to several outcomes is one card, not several copies. It should remain the same plan when seen in a unit stack, the week, the term, or Teaching Mode.

## Respect the teacher's existing work

The teacher leads progression and pacing. Calendar calculations reveal capacity and conflicts; they do not replace professional judgment or silently move plans.

Four Square organizes the teaching. Google Drive holds the materials. Teachers should be able to link to resources wherever those resources already live without creating a new folder system. Original files must never be silently moved, renamed, or modified. The same workbook can support different lessons through different page selections without duplicating the original.

The planner should be useful without Google Drive. Future integrations should request the minimum access needed and explain when files need reconnecting. Student data should be minimized.

## Start narrow, preserve the ambition

The first prototype should validate digital cards, nested stacks, basic term planning, and calendar-based instructional time. Later phases can connect Drive selection, focused daily teaching, print preparation, slides, resource processing, and publisher integrations.

The eventual business could begin with Alberta curriculum and teacher validation, followed by partnerships or licensing. The immediate goal is to discover whether the connected planning workflow reduces teachers' workload. Do not mistake the quantity of features for success.
